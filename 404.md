# How to install
Paste this link into the Install Plugin section of Revenge client.

https://dxckie-cell.github.io/Override-User-Avatars-Revenge-Plugin-/Override-User-Avatars/

Supports overriding the profile picture of multiple users. In the plugin settings, tap "+ Add user" and enter each user's ID and image URL. Changes apply immediately.

# Known Issues
Does not change the profile picture on notifications.

# Read All
Adds an eye button to the guild bar that marks unread servers and DMs as read. Tap it to choose between Mark All Read, Servers Only, or DMs Only. Server and DM/group IDs can be excluded in the plugin settings.

https://dxckie-cell.github.io/Override-User-Avatars-Revenge-Plugin-/ReadAll/

Fork of [ReadAll](https://github.com/ApexTeamPL/Apex-Plugins/tree/master/plugins/ReadAll) from ApexTeamPL/Apex-Plugins (CC0). Original authors: Win8.1VMUser, btmc727, fshin.
